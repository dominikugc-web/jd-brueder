# JD Brüder – Website

Neue Website von JD Brüder (Fahrzeugaufbereitung, Puderbach/Westerwald) als statische Seite für GitHub Pages.

- `index.html` – Startseite (Pakete, Preise, Vorher/Nachher, Trockeneis, Galerie, Über uns, FAQ, Kontakt)
- `impressum.html`, `datenschutz.html` – Rechtstexte
- `style.css`, `main.js` – Gestaltung und kleine Funktionen (Vorher/Nachher-Regler, Bildvergrößerung, Kontaktleiste)
- `img/` – eigene Fotos (Web-Größe) und Logos, `fonts/` – lokal eingebundene Schriften

Preise ändern: in `index.html` nach dem Paketnamen suchen und den Betrag anpassen.
